Claude Code 신입 개발자 온보딩 — 첫 기능부터 첫 PR까지

이 책에 대하여 (머리말)

이 책의 목적

이 책의 목적은 Python·웹 백엔드 기초가 있는 주니어 개발자가 Claude Code를 처음 익혀, 기존 팀의 FastAPI 저장소에 작은 기능 하나를 안전하게 추가하고 테스트와 함께 리뷰어가 신뢰할 수 있는 '첫 PR'까지 올리는 온보딩 여정을 끝까지 해내게 하는 것입니다. Claude Code의 기능을 백과사전처럼 나열하지 않고, 신입의 실제 첫 업무 흐름(설치 → 코드베이스 파악 → 안전하게 변경 → 검증 → 팀 규약 → 커밋·PR → 리뷰 대응 → 디버깅)에 맞춰 필요한 만큼만 배웁니다.

이 책을 마치면 할 수 있는 것

  • Claude Code를 설치·인증하고 대화형 세션에서 에이전트와 일하는 흐름을 운용할 수 있습니다
  • 낯선 팀 코드베이스를 에이전트 탐색으로 빠르게 파악하고, 권한·플랜 모드로 안전하게 변경할 수 있습니다
  • 변경을 pytest 실행·테스트로 검증하고, CLAUDE.md로 팀 규약을 주입할 수 있습니다
  • 작은 논리 단위로 커밋해 첫 PR을 올리고, 코드 리뷰에 근거 있게 대응하며, 에이전트와 함께 디버깅할 수 있습니다
  • 종합 프로젝트로 기존 FastAPI 저장소에 '완료 처리·상태 필터' 기능을 추가해 테스트와 함께 첫 PR을 완성할 수 있습니다

대상 독자

Python 기초 문법과 웹 백엔드(HTTP·REST)의 기본 개념을 갖춘 주니어 개발자로, Claude Code(에이전트형 코딩 도구)는 처음 쓰는 분. 컴퓨터공학 전공 여부는 무관하지만, 아래 선수 지식은 가정합니다(전공이 아니라 '아래를 아는가'가 기준입니다).

선수 지식

  • Python 기초 문법: 함수·조건문·리스트/딕셔너리·모듈 import를 읽고 쓸 수 있음(코드를 처음 보는 수준이면 먼저 Python 입문을 권합니다)
  • 터미널·명령줄 기본: 디렉터리 이동(cd)·명령 실행·환경 변수 개념
  • git 기본: add·commit·branch·PR(Pull Request)이 무엇인지 아는 정도(능숙할 필요는 없음 — 9장에서 Claude Code와 함께 익힙니다)
  • HTTP·REST 기초: GET/POST 같은 메서드와 상태 코드(200·404 등)의 의미
  • FastAPI는 몰라도 됩니다: 실습 저장소(team-tasks-api)의 코드를 '읽을 수 있으면' 충분하며, 필요한 부분은 본문에서 설명합니다

실습 환경

  • 운영체제: Windows 11 기준(명령은 macOS·Linux에도 대응; 차이는 그때그때 표기)
  • Python 3.10 이상과 Git for Windows(Git Bash)
  • Claude 구독(Pro/Max) 또는 API 키 — 1장에서 인증 방법을 안내
  • 공용 실습 저장소: team-tasks-api(이 책의 assets/에 포함; 1장에서 git init·pip·pytest로 셋업)
