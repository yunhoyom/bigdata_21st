10장. JavaScript 함수와 자료구조¶

학습 목표 - 함수 선언·표현식·화살표 함수를 상황에 맞게 작성할 수 있습니다 - 스코프와 클로저의 기본 개념을 설명할 수 있습니다 - 배열과 객체로 데이터를 구조화하고 조작할 수 있습니다 - map·filter·reduce 등 고차 메서드로 데이터를 선언적으로 처리할 수 있습니다

10.1 함수로 코드 재사용하기¶

도입¶

같은 계산을 여러 곳에서 반복해야 한다고 생각해 보십시오. 코드를 복사·붙여넣기 하면 당장은 동작하지만, 나중에 수정할 때 모든 복사본을 찾아서 고쳐야 합니다. 함수(Function)는 이 문제를 해결합니다. 재료를 넣으면 정해진 음식을 만들어 내주는 요리 기계처럼, 함수는 입력을 받아 결과를 돌려주는 코드 묶음입니다.

핵심 개념 설명¶

함수 선언문(Function Declaration)¶

함수를 정의하는 가장 전통적인 방법입니다. function 키워드 뒤에 이름을 붙이고, 괄호 안에 매개변수(Parameter)를 나열합니다.

// 이름과 나이를 받아 인사 메시지를 반환하는 함수
function greet(name, age) {
  const message = `안녕하세요, ${name}님! 만 ${age}세이시군요.`;
  return message;
}

const result = greet("김민준", 28);
console.log(result);

// 콘솔 출력: 안녕하세요, 김민준님! 만 28세이시군요.

줄별 코드 설명

줄 코드 설명
2 function greet(name, age) { greet라는 이름의 함수를 선언합니다. name과 age는 매개변수입니다
3 const message = \...`` 템플릿 리터럴로 인사 문자열을 조합하여 변수에 저장합니다
4 return message; 호출한 곳으로 값을 돌려줍니다. return 이후 코드는 실행되지 않습니다

팁: 함수 선언문은 호이스팅(Hoisting)이 됩니다. 즉, 선언보다 위에서 호출해도 오류가 나지 않습니다. 하지만 코드를 위에서 아래로 읽을 수 있도록 선언 후 사용하는 습관을 권장합니다.

함수 표현식(Function Expression)¶

함수를 변수에 할당하는 방식입니다. 변수 이름이 곧 함수의 이름 역할을 합니다.

// 함수를 변수에 담는 함수 표현식
const square = function (n) {
  return n * n;
};

console.log(square(5));
console.log(square(9));

// 콘솔 출력: 25
// 콘솔 출력: 81

줄별 코드 설명

줄 코드 설명
2 const square = function (n) { 이름이 없는 익명 함수를 만들어 square 변수에 할당합니다
3 return n * n; 매개변수 n의 제곱값을 반환합니다
6 square(5) square 변수를 통해 함수를 호출합니다

주의: 함수 표현식은 호이스팅이 되지 않습니다. 선언 이전에 호출하면 ReferenceError가 발생합니다.

화살표 함수(Arrow Function)¶

ES2015에서 도입된 더 짧은 함수 표기법입니다. => 기호를 사용하며 콜백 함수로 자주 쓰입니다.

// 화살표 함수의 다양한 형태
const add = (a, b) => a + b;                    // 식이 한 줄이면 중괄호와 return 생략 가능
const double = n => n * 2;                       // 매개변수가 하나면 괄호 생략 가능
const sayHello = () => console.log("안녕하세요!"); // 매개변수 없으면 빈 괄호 필수

console.log(add(3, 7));
console.log(double(6));
sayHello();

// 콘솔 출력: 10
// 콘솔 출력: 12
// 콘솔 출력: 안녕하세요!

줄별 코드 설명

줄 코드 설명
2 (a, b) => a + b 중괄호와 return 없이 표현식 결과를 바로 반환합니다
3 n => n * 2 매개변수가 하나일 때 괄호를 생략할 수 있습니다
4 () => console.log(...) 매개변수가 없을 때는 빈 괄호 ()를 반드시 씁니다

매개변수 심화: 기본값과 나머지 매개변수¶

기본 매개변수(Default Parameter)는 인자가 전달되지 않았을 때 사용할 값을 지정합니다. 나머지 매개변수(Rest Parameter)는 여러 인자를 배열로 모아 받습니다.

// 기본값 매개변수: 단위 미지정 시 'km'를 기본값으로 사용
function formatDistance(value, unit = "km") {
  return `${value}${unit}`;
}

// 나머지 매개변수: 개수에 관계없이 숫자들을 합산
const sumAll = (...numbers) => {
  return numbers.reduce((total, n) => total + n, 0);
};

console.log(formatDistance(42));
console.log(formatDistance(1500, "m"));
console.log(sumAll(1, 2, 3, 4, 5));

// 콘솔 출력: 42km
// 콘솔 출력: 1500m
// 콘솔 출력: 15

줄별 코드 설명

줄 코드 설명
2 unit = "km" unit에 값을 전달하지 않으면 "km"가 기본값으로 사용됩니다
7 (...numbers) ... 앞에 붙으면 나머지 매개변수입니다. 여러 인자를 배열로 받습니다
8 numbers.reduce(...) 받은 배열을 reduce로 모두 더합니다(reduce는 10.5절에서 자세히 다룹니다)

함수 선언문 vs 표현식 vs 화살표 함수 비교¶

구분 호이스팅 this 바인딩 주 사용처
함수 선언문 O (전체) 호출 방식에 따름 모듈의 주요 함수
함수 표현식 X 호출 방식에 따름 조건부 함수 정의
화살표 함수 X 상위 스코프 상속 콜백, 짧은 변환 함수

절 요약¶

  • 함수는 재사용 가능한 코드 묶음으로, 함수 선언문·표현식·화살표 함수 세 가지 방식으로 작성합니다
  • 화살표 함수는 한 줄 표현식에서 중괄호와 return을 생략할 수 있어 간결합니다
  • 기본 매개변수로 인자 누락 시 기본값을 지정하고, 나머지 매개변수로 가변 인자를 배열로 받습니다

10.2 스코프와 클로저 맛보기¶

도입¶

코드를 작성하다 보면 변수가 어디서 어디까지 보이는지 헷갈릴 때가 있습니다. 스코프(Scope)는 변수가 유효한 범위를 의미합니다. 그리고 클로저(Closure)는 함수가 자신이 만들어진 환경을 기억하는 특성으로, JavaScript의 핵심 동작 원리 중 하나입니다.

핵심 개념 설명¶

전역 스코프와 지역 스코프¶

함수 바깥에 선언된 변수는 전역 스코프(Global Scope)에 속하며 어디서든 접근할 수 있습니다. 함수 안에 선언된 변수는 지역 스코프(Local Scope)에 속하며 함수 밖에서는 접근할 수 없습니다.

const globalName = "전역 변수";  // 전역 스코프

function showScope() {
  const localName = "지역 변수";  // 지역 스코프 (함수 안에서만 유효)
  console.log(globalName);       // 전역 변수 접근 가능
  console.log(localName);        // 지역 변수 접근 가능
}

showScope();
console.log(globalName);         // 전역 변수 접근 가능
// console.log(localName);       // ReferenceError: localName is not defined

// 콘솔 출력: 전역 변수
// 콘솔 출력: 지역 변수
// 콘솔 출력: 전역 변수

줄별 코드 설명

줄 코드 설명
1 const globalName = "전역 변수" 함수 바깥에 선언되어 파일 어디서든 접근 가능합니다
4 const localName = "지역 변수" showScope 함수 안에서만 유효한 변수입니다
10 // console.log(localName) 함수 밖에서는 localName에 접근할 수 없어 오류가 납니다

블록 스코프(Block Scope)¶

const와 let은 { } 블록 단위 스코프를 가집니다. if, for, while의 중괄호도 스코프 경계가 됩니다.

if (true) {
  const blockVar = "블록 안 변수";
  let blockLet = "블록 안 let";
  console.log(blockVar); // 정상 접근
}
// console.log(blockVar);  // ReferenceError: blockVar is not defined
// console.log(blockLet);  // ReferenceError: blockLet is not defined

for (let i = 0; i < 3; i++) {
  console.log(i); // 0, 1, 2
}
// console.log(i);  // ReferenceError: i is not defined

// 콘솔 출력: 블록 안 변수
// 콘솔 출력: 0
// 콘솔 출력: 1
// 콘솔 출력: 2

스코프 체인(Scope Chain)¶

내부 함수는 자신의 스코프에서 변수를 찾고, 없으면 바깥 스코프로 올라가며 찾습니다. 이 연쇄 탐색 과정을 스코프 체인이라고 합니다.

const outer = "바깥 변수";

function outerFn() {
  const middle = "중간 변수";

  function innerFn() {
    const inner = "안쪽 변수";
    // 안쪽 → 중간 → 전역 순으로 변수를 찾습니다
    console.log(inner);   // 자신의 스코프에서 발견
    console.log(middle);  // 바깥 함수 스코프에서 발견
    console.log(outer);   // 전역 스코프에서 발견
  }

  innerFn();
}

outerFn();

// 콘솔 출력: 안쪽 변수
// 콘솔 출력: 중간 변수
// 콘솔 출력: 바깥 변수

줄별 코드 설명

줄 코드 설명
6 function innerFn() { outerFn 안에 정의된 중첩 함수입니다
9 console.log(middle) innerFn의 스코프에 없으므로 한 단계 위인 outerFn 스코프에서 찾습니다
10 console.log(outer) 함수 스코프에 없으므로 전역 스코프에서 찾습니다

클로저(Closure)의 개념과 활용¶

클로저는 함수가 선언될 때의 외부 변수(렉시컬 환경)를 기억하여, 그 함수가 바깥에서 호출되어도 해당 변수에 계속 접근할 수 있는 특성입니다. 도시락을 싸 온 사람이 밖에 나가서도 집에서 담아 온 반찬을 꺼내 먹을 수 있는 것과 같습니다.

아래 예제는 클로저를 이용해 카운터를 만듭니다. 내부 함수가 바깥 변수 count를 기억한 채로 반환됩니다.

// 클로저로 카운터 만들기
function makeCounter() {
  let count = 0;  // 이 변수는 반환된 함수가 기억합니다

  return function () {
    count += 1;
    console.log(`현재 카운트: ${count}`);
  };
}

const counter = makeCounter();  // makeCounter 실행 후 내부 함수만 반환
counter();  // count를 기억한 채 실행
counter();
counter();

// 콘솔 출력: 현재 카운트: 1
// 콘솔 출력: 현재 카운트: 2
// 콘솔 출력: 현재 카운트: 3

줄별 코드 설명

줄 코드 설명
2 let count = 0 makeCounter 스코프의 변수. 반환된 함수가 이 변수를 클로저로 기억합니다
4 return function () { 익명 함수를 반환합니다. 이 함수가 count를 참조하여 클로저가 만들어집니다
10 const counter = makeCounter() makeCounter는 실행되어 사라지지만, 반환된 함수는 count를 살아있게 합니다
11 counter() 호출할 때마다 count가 누적됩니다

팁: 클로저는 어렵고 특수한 기능처럼 느껴지지만, 함수가 외부 변수를 참조하면 자연스럽게 발생합니다. 앞선 makeCounter 예제처럼 상태를 안전하게 캡슐화할 때 매우 유용합니다.

베스트 프랙티스: 클로저로 만든 변수는 외부에서 직접 수정할 수 없습니다. 이 특성을 이용해 전역 변수 오염 없이 상태를 관리하는 패턴이 실무에서 자주 쓰입니다.

절 요약¶

  • 변수는 선언된 위치에 따라 전역·지역·블록 스코프를 가집니다
  • 내부 함수는 스코프 체인을 통해 바깥 스코프의 변수에 접근합니다
  • 클로저는 함수가 선언 당시의 렉시컬 환경을 기억하는 특성으로, 상태 캡슐화에 활용됩니다

10.3 배열 다루기¶

도입¶

여러 데이터를 하나로 묶어 관리해야 할 때 배열(Array)을 사용합니다. 번호가 매겨진 사물함 한 줄에 물건을 차례로 넣어 두는 것과 같습니다. JavaScript의 배열은 다양한 내장 메서드를 제공하여 데이터 조작을 편리하게 합니다.

핵심 개념 설명¶

배열 생성과 인덱스 접근¶

배열은 대괄호 []로 만들고, 0부터 시작하는 인덱스(Index)로 각 요소에 접근합니다.

// 배열 생성과 기본 접근
const fruits = ["사과", "바나나", "딸기", "포도"];

console.log(fruits[0]);          // 첫 번째 요소
console.log(fruits[2]);          // 세 번째 요소
console.log(fruits.length);      // 배열 길이
console.log(fruits[fruits.length - 1]); // 마지막 요소

// 콘솔 출력: 사과
// 콘솔 출력: 딸기
// 콘솔 출력: 4
// 콘솔 출력: 포도

줄별 코드 설명

줄 코드 설명
2 const fruits = [...] 배열 리터럴로 생성합니다. const이지만 배열의 내용은 변경할 수 있습니다
4 fruits[0] 인덱스는 0부터 시작합니다. 첫 번째 요소는 fruits[0]입니다
6 fruits.length 배열에 담긴 요소의 개수를 반환합니다
7 fruits[fruits.length - 1] length - 1이 마지막 인덱스입니다

Array.prototype.length

항목 내용
설명 배열에 담긴 요소의 개수를 반환합니다
타입 number (읽기/쓰기 가능)
사용 예시 [1, 2, 3].length → 3

요소 추가·제거 메서드¶

const colors = ["빨강", "파랑"];

// 끝에 추가 / 제거
colors.push("초록");           // 끝에 "초록" 추가
const last = colors.pop();    // 끝 요소("초록") 제거 후 반환

// 앞에 추가 / 제거
colors.unshift("노랑");        // 앞에 "노랑" 추가
const first = colors.shift(); // 앞 요소("노랑") 제거 후 반환

console.log(colors);
console.log(`제거된 마지막: ${last}, 제거된 첫 번째: ${first}`);

// 콘솔 출력: ["빨강", "파랑"]

slice와 splice의 차이¶

두 메서드는 이름이 비슷하지만 동작이 다릅니다. slice는 원본을 건드리지 않고 복사하고, splice는 원본을 직접 수정합니다.

const numbers = [10, 20, 30, 40, 50];

console.log(sliced);                // [20, 30, 40]
console.log(numbers);               // 원본 변경 없음

// splice: 원본 수정, 지정 위치에서 요소를 제거하거나 삽입
const removed = numbers.splice(1, 2); // 인덱스 1부터 2개 제거
console.log(removed);               // [20, 30] (제거된 요소)
console.log(numbers);               // [10, 40, 50] (원본 변경됨)

// 콘솔 출력: [20, 30, 40]
// 콘솔 출력: [10, 20, 30, 40, 50]
// 콘솔 출력: [20, 30]
// 콘솔 출력: [10, 40, 50]

10.4 객체로 데이터 구조화하기¶

이름·나이·직업처럼 관련된 여러 정보를 하나로 묶고 싶을 때 객체(Object)를 사용합니다. 이름·나이·주소 항목이 적힌 신분증처럼, 객체는 관련 정보를 하나의 단위로 묶어 의미 있게 다룹니다.

10.5 고차 배열 메서드: map, filter, reduce¶

도입¶

배열을 처리할 때 for문을 직접 쓸 수도 있지만, JavaScript는 더 읽기 쉬운 방법을 제공합니다. 고차 함수(Higher-order Function)는 다른 함수를 인자로 받거나 반환하는 함수입니다. map, filter, reduce는 배열을 선언적(declarative)으로 처리하는 대표적인 고차 메서드입니다. 공장 컨베이어에서 가공(map)·선별(filter)·합산(reduce) 공정을 차례로 거치는 것과 같습니다.

핵심 개념 설명¶

콜백 함수(Callback Function)¶

콜백 함수는 다른 함수에 인자로 전달되어, 그 함수가 적절한 시점에 호출하는 함수입니다. map, filter, reduce는 모두 콜백 함수를 받아 배열의 각 요소에 적용합니다.

// 콜백 함수의 기본 개념
const numbers = [1, 2, 3, 4, 5];

// 콜백 함수를 변수에 담아 전달
const isEven = (n) => n % 2 === 0;

const evens = numbers.filter(isEven);  // isEven이 콜백 함수
console.log(evens);

// 콘솔 출력: [2, 4]

    Array.prototype.reduce(callbackFn, initialValue?)

    항목 내용
    설명 배열의 각 요소에 대해 콜백 함수를 실행하고, 하나의 누적 결과 값을 반환합니다
    매개변수 callbackFn(accumulator, currentValue, currentIndex, array): 요소마다 호출되는 누적 함수
    initialValue (any, 선택): 첫 번째 accumulator 초기값. 생략 시 배열의 첫 요소가 됩니다
    반환값 누적 계산의 최종 결과값
    사용 예시 [1, 2, 3, 4].reduce((sum, n) => sum + n, 0) → 10

    forEach vs map 비교¶

    const nums = [1, 2, 3];

// forEach: 반환값 없음. 부수 효과(콘솔 출력, DOM 조작 등)를 위해 사용
nums.forEach((n) => console.log(n * 10));

// map: 새 배열 반환. 변환 결과가 필요할 때 사용
const doubled = nums.map((n) => n * 10);
console.log(doubled);

// 콘솔 출력: 20
// 콘솔 출력: 30

    베스트 프랙티스: 변환된 결과가 필요하면 map을, 결과 없이 각 요소에 작업만 하면 forEach를 사용하십시오. map의 반환값을 사용하지 않는 패턴은 의도를 불명확하게 합니다.

    비교 테이블: map, filter, reduce, forEach¶

    메서드 반환값 원본 변경 주요 용도
    map 새 배열 X 각 요소 변환
    filter 새 배열(일부) X 조건에 맞는 요소 추출
    reduce 단일 값 (모든 타입 가능) X 누적 계산, 합산, 집계
    forEach undefined X (콜백에서 원본 수정 가능) 순회 후 부수 효과 실행

    FAQ¶

    Q1. 화살표 함수와 일반 함수는 언제 무엇을 써야 하나요?

    A1. 짧은 변환 로직이나 콜백 함수로 쓸 때는 화살표 함수가 간결합니다. 반면 객체의 메서드를 정의하거나 this를 사용해야 하는 경우에는 일반 함수(메서드 단축 표기)를 사용하십시오. 화살표 함수는 자신만의 this를 가지지 않기 때문에 메서드 내부에서 this.속성에 접근하면 의도치 않은 값이 됩니다.

    Q2. const로 선언한 배열이나 객체도 내용을 바꿀 수 있나요?

    A2. 네, 가능합니다. const는 변수 자체의 재할당을 막을 뿐, 배열이나 객체 내부의 값 변경은 허용합니다. 예를 들어 const arr = [1]로 선언한 뒤 arr.push(2)는 허용되지만, arr = [1, 2]처럼 새 배열을 할당하는 것은 오류가 납니다.

    Q3. reduce의 초기값(initialValue)을 언제 꼭 써야 하나요?

    A3. 배열이 비어 있을 가능성이 있을 때 반드시 초기값을 지정하십시오. 빈 배열에 초기값 없이 reduce를 호출하면 TypeError가 발생합니다. 또한 누적값의 타입이 배열 요소의 타입과 다를 때(예: 숫자 배열을 객체로 변환하는 경우)에도 초기값이 필요합니다. 습관적으로 초기값을 명시하는 것을 권장합니다.

    Q4. map과 filter의 원본 배열이 변경되지 않는다고 했는데, 어떻게 확인하나요?

    A4. 다음처럼 직접 확인할 수 있습니다.

    const original = [1, 2, 3, 4, 5];
const result = original.filter((n) => n > 3);

console.log(original); // [1, 2, 3, 4, 5] — 그대로
console.log(result);   // [4, 5]

    map과 filter는 항상 새 배열을 반환하므로 원본은 안전합니다.

    Q5. 클로저가 메모리 누수를 일으킬 수 있다고 들었습니다. 어떤 경우인가요?

    A5. 클로저가 참조하는 외부 변수는 가비지 컬렉터가 수거하지 않습니다. 이벤트 리스너 안에서 큰 객체를 클로저로 참조하고 리스너를 제거하지 않으면 메모리에 계속 남습니다. 11장에서 이벤트 리스너를 학습할 때 removeEventListener로 정리하는 습관을 함께 익히면 됩니다.

124    const totalPriceEl = document.getElementById("total-price");
125
126    const renderCart = () => {
127      cartListEl.innerHTML = "";  // 기존 목록을 초기화합니다 (다시 채우기 위해)
128
129      const currentItems = cart.getItems();  // 현재 장바구니 복사본
130
131      if (currentItems.length === 0) {
132        // 빈 장바구니 메시지 — textContent로 안전하게 텍스트를 설정합니다
133        const emptyLi = document.createElement("li");
134        emptyLi.className = "empty-msg";
135        emptyLi.textContent = "장바구니가 비어 있습니다";  // innerHTML 대신 textContent를 사용합니다
136        cartListEl.appendChild(emptyLi);
137        totalPriceEl.textContent = "0원";
138        return;
139      }
140
141      // 각 상품을 li 요소로 만들어 목록에 추가합니다
142      currentItems.forEach(({ name, price, qty }) => {
143        const subtotal = price * qty;  // 소계 계산
144
145        const li = document.createElement("li");
146        li.className = "cart-item";
147
148        // 상품 이름 — textContent로 XSS를 방지합니다
149        const nameSpan = document.createElement("span");
150        nameSpan.className = "item-name";
151        nameSpan.textContent = name;  // innerHTML 대신 textContent 사용
152
153        // 가격 정보
154        const priceSpan = document.createElement("span");
155        priceSpan.className = "item-price";
156        priceSpan.textContent = `${price.toLocaleString()}원 × ${qty} = ${subtotal.toLocaleString()}원`;
157
158        // 삭제 버튼 — data-name 속성에 상품 이름을 저장합니다
159        const removeBtn = document.createElement("button");
160        removeBtn.className = "btn-remove";
161        removeBtn.textContent = "삭제";
162        removeBtn.dataset.name = name;  // 이벤트 핸들러에서 읽을 수 있도록 저장합니다
163        removeBtn.addEventListener("click", (e) => {
164          const itemName = e.target.dataset.name;  // 버튼의 data-name 속성을 읽습니다
165          cart.removeItem(itemName);  // 클로저 내 items에서 해당 상품을 제거합니다
166          renderCart();              // UI를 다시 그립니다
167        });
168
169        li.appendChild(nameSpan);
170        li.appendChild(priceSpan);
171        li.appendChild(removeBtn);
172        cartListEl.appendChild(li);
173      });
174
175      // 합계 갱신
176      const total = cart.getTotal();
177      totalPriceEl.textContent = `${total.toLocaleString()}원`;
178    };
179
180    // ============================================================
181    // 장바구니 인스턴스 생성 및 이벤트 연결
182    // ============================================================
183    const cart = createCart();  // 클로저 기반 장바구니 인스턴스
184
185    // 추가 버튼 클릭 이벤트 — querySelectorAll로 모든 버튼을 선택하고 forEach로 이벤트 연결
186    document.querySelectorAll(".btn-add").forEach((btn) => {
187      btn.addEventListener("click", () => {
188        const name = btn.dataset.name;            // 버튼의 data-name 속성에서 상품 이름을 읽습니다
189        const price = Number(btn.dataset.price);  // 문자열 가격을 숫자로 변환합니다
190        cart.addItem(name, price);  // 클로저 내 items를 조작합니다
191        renderCart();              // 상태 변경 후 UI를 즉시 갱신합니다
192      });
193    });
194
195    // 초기 렌더링 — 페이지 로드 시 빈 장바구니를 표시합니다
196    renderCart();
197

200    // ============================================================

202      const items = cart.getItems();
203
204      if (items.length === 0) {
205        console.log("장바구니가 비어 있습니다.");
206        return;
207      }
208
209      console.log("--- 장바구니 요약 ---");
210
211      // map으로 각 상품을 요약 문자열로 변환합니다
212      const summary = items.map(
213        ({ name, price, qty }) => `${name}: ${price.toLocaleString()}원 × ${qty}`
214      );
215      summary.forEach((line) => console.log(line));
216
217      console.log(`총 상품 종류: ${items.length}가지`);
218      console.log(`합계: ${cart.getTotal().toLocaleString()}원`);
219    };
220
221    // 브라우저 콘솔에서 printCartSummary()를 직접 호출해 볼 수 있습니다
222    console.log("콘솔에서 printCartSummary()를 입력하여 현재 장바구니를 확인하십시오.");
