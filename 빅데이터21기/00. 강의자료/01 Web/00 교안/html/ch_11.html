11장: DOM 조작과 이벤트 처리

중급

DOM 조작과 이벤트 처리¶

학습 목표 - DOM 트리와 노드 구조를 이해하고 설명할 수 있습니다 - 요소를 선택·생성·삭제하여 페이지를 동적으로 변경할 수 있습니다 - addEventListener와 이벤트 객체로 사용자 상호작용을 처리할 수 있습니다 - 캡처링·버블링을 이해하고 이벤트 위임으로 효율적인 UI를 구현할 수 있습니다

DOM 트리 이해하기¶

도입¶

지금까지 HTML로 구조를 만들고 CSS로 꾸몄습니다. 이제 JavaScript가 무대에 오를 차례입니다. JavaScript가 웹 페이지를 "조작"한다고 할 때, 실제로는 DOM(Document Object Model)이라는 중간 계층을 통해 작업합니다. DOM이 무엇인지 이해하면, 버튼 클릭으로 내용을 바꾸거나 새 항목을 추가하는 모든 동적 기능의 원리가 명확해집니다.

핵심 개념 설명¶

DOM(Document Object Model)이란¶

DOM(Document Object Model, 문서 객체 모델)은 브라우저가 HTML 문서를 읽어 들인 뒤 JavaScript가 다룰 수 있도록 변환한 객체 트리(tree of objects)입니다.

브라우저가 HTML 파일을 해석하면, 단순한 텍스트 문자열이 아닌 서로 연결된 노드(Node) 들의 집합체로 바뀝니다. JavaScript는 이 노드들을 읽고, 수정하고, 추가하고, 삭제할 수 있습니다.

비유: 가계도처럼 부모-자식 관계로 연결된 가족 나무를 생각해 보십시오. html이 뿌리이고, 그 아래 head와 body가 가지를 치며, 각 가지에서 또 자식 요소들이 뻗어 나옵니다. JavaScript는 이 가계도를 보면서 원하는 가족 구성원을 찾아 정보를 변경할 수 있습니다.

중요: DOM과 HTML 소스 코드는 같지 않습니다. JavaScript로 DOM을 변경하면 화면은 바뀌지만 원본 .html 파일은 그대로입니다. 브라우저 개발자 도구의 "Elements" 탭에서 보이는 것이 바로 현재 DOM 상태입니다.

노드의 종류¶

DOM 트리를 구성하는 노드(Node)에는 세 가지 주요 종류가 있습니다.

노드 종류 설명 예시
요소 노드(Element Node) HTML 태그 하나하나 <p>, <ul>, <div>
텍스트 노드(Text Node) 태그 사이의 텍스트 "안녕하세요"
속성 노드(Attribute Node) 요소의 속성 class="btn", href="/"

가장 많이 다루는 것은 요소 노드이며, 속성은 요소 노드의 일부로 취급합니다.

HTML과 DOM 트리의 관계¶

다음 HTML을 보면서 DOM 트리가 어떻게 형성되는지 살펴봅시다.

코드로 확인하기¶

document 객체는 DOM의 진입점(entry point)입니다. document를 통해 페이지의 모든 요소에 접근할 수 있습니다.

<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>DOM 탐색 실습</title>
</head>
<body>
  <ul id="fruits">
    <li class="item">사과</li>
    <li class="item">바나나</li>
    <li class="item">포도</li>
  </ul>

  <script>
    // document가 DOM의 최상위 객체입니다
    console.log(document.title);           // 콘솔 출력: DOM 탐색 실습

    // body 요소 자체에 접근합니다
    console.log(document.body);            // 콘솔 출력: <body>...</body>

    // id로 요소를 찾습니다
    const list = document.getElementById('fruits');
    console.log(list);                     // 콘솔 출력: <ul id="fruits">...</ul>

    // 자식 요소들의 개수를 확인합니다
    console.log(list.children.length);     // 콘솔 출력: 3

    // 첫 번째 자식 요소를 확인합니다
    console.log(list.firstElementChild.textContent); // 콘솔 출력: 사과
  </script>
</body>
</html>

DOM 탐색 실습
<body>...</body>
<ul id="fruits">...</ul>
3

절 요약¶

  • DOM은 브라우저가 HTML을 파싱해 만드는 객체 트리이며, JavaScript의 조작 대상입니다
  • 트리의 각 구성원을 노드라 하고, 요소·텍스트·속성 노드로 나뉩니다
  • document 객체가 DOM의 최상위 진입점이며 모든 탐색은 여기서 시작합니다

요소 선택하고 조작하기¶

도입¶

DOM 트리가 무엇인지 알았다면, 이제 원하는 요소를 "찾아" 내용을 바꾸는 작업을 배울 차례입니다. 이 절에서는 현대 JavaScript에서 표준으로 사용되는 querySelector와 querySelectorAll을 중심으로, 텍스트 변경·스타일 변경·클래스 조작까지 모두 다룹니다. 특히 innerHTML과 textContent의 보안 차이는 반드시 짚어야 할 핵심 내용입니다.

핵심 개념 설명¶

querySelector / querySelectorAll¶

document.querySelector(selector)

항목 내용
설명 CSS 선택자와 일치하는 첫 번째 요소를 반환합니다
매개변수 selector (string, 필수): CSS 선택자 문자열
반환값 Element - 일치하는 첫 번째 요소, 없으면 null
예외 SyntaxError - 선택자 문법이 잘못된 경우
사용 예시 document.querySelector('.btn') → 클래스가 btn인 첫 번째 요소

document.querySelectorAll(selector)

항목 내용
설명 CSS 선택자와 일치하는 모든 요소를 NodeList로 반환합니다
매개변수 selector (string, 필수): CSS 선택자 문자열
반환값 NodeList - 일치하는 모든 요소의 정적 컬렉션
사용 예시 document.querySelectorAll('li') → 모든 <li> 요소 목록

textContent와 innerHTML의 차이 — 보안 주의¶

요소의 내용을 바꿀 때 textContent와 innerHTML 중 무엇을 써야 할지 반드시 알아야 합니다.

속성 설명 보안
textContent 텍스트만 처리. HTML 태그를 문자 그대로 표시 안전
innerHTML HTML을 파싱하여 실제 요소로 삽입 주의 필요

보안 경고(XSS 취약점): innerHTML에 사용자 입력을 직접 대입하면 XSS(Cross-Site Scripting, 교차 사이트 스크립팅) 공격에 노출됩니다. 예를 들어 사용자가 <img src='x' onerror='악성코드()'> 같은 문자열을 입력하면 그 코드가 실행됩니다. 사용자 입력 값은 반드시 textContent로 처리하십시오.

classList로 클래스 조작하기¶

요소의 CSS 클래스를 JavaScript로 추가·제거·토글하는 가장 안전하고 권장되는 방법은 classList API입니다.

element.classList

항목 내용
설명 요소의 CSS 클래스 목록을 관리하는 DOMTokenList 객체
주요 메서드 add('cls') — 클래스 추가
remove('cls') — 클래스 제거
toggle('cls') — 있으면 제거, 없으면 추가
contains('cls') — 포함 여부 boolean 반환
사용 예시 btn.classList.toggle('active')

코드로 확인하기¶

다음 코드는 querySelector로 요소를 선택하고, textContent와 classList로 내용과 스타일을 동적으로 변경하는 예제입니다.

<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>요소 조작 예제</title>
  <style>
    .highlight { background-color: #fff3cd; font-weight: bold; }
    .completed { text-decoration: line-through; color: #999; }
    #status { margin-top: 12px; font-size: 0.9rem; color: #555; }
  </style>
</head>
<body>
  <h2 id="heading">오늘의 할 일</h2>
  <ul id="task-list">
    <li id="task-1">장보기</li>
    <li id="task-2">운동하기</li>
    <li id="task-3">독서하기</li>
  </ul>
  <button id="btn-complete">첫 번째 완료 처리</button>
  <button id="btn-highlight">제목 강조 토글</button>
  <p id="status"></p>

  <script>
    // 요소를 선택합니다
    const heading   = document.querySelector('#heading');
    const firstTask = document.querySelector('#task-1');
    const allTasks  = document.querySelectorAll('#task-list li');
    const statusEl  = document.querySelector('#status');

    // textContent로 안전하게 텍스트를 변경합니다
    statusEl.textContent = `총 ${allTasks.length}개의 할 일이 있습니다.`;

    // classList로 클래스를 추가합니다
    document.querySelector('#btn-complete').addEventListener('click', () => {
      firstTask.classList.add('completed');
      firstTask.textContent = '장보기 (완료)';
    });

    // classList.toggle로 클래스를 켜고 끕니다
    document.querySelector('#btn-highlight').addEventListener('click', () => {
      heading.classList.toggle('highlight');
    });

    // 모든 li 요소를 순회합니다
    allTasks.forEach((task, index) => {
      console.log(`${index + 1}번 작업: ${task.textContent}`);
    });
  </script>
</body>
</html>

브라우저 동작 결과: - 페이지 로드 시 하단에 "총 3개의 할 일이 있습니다." 텍스트가 표시됩니다 - "첫 번째 완료 처리" 버튼 클릭 → "장보기" 항목에 취소선이 생기고 회색으로 바뀝니다 - "제목 강조 토글" 버튼 클릭 → 제목 배경이 노란색으로 바뀌고 다시 클릭하면 원래대로 돌아옵니다

콘솔 출력:

1번 작업: 장보기
2번 작업: 운동하기
3번 작업: 독서하기

줄별 코드 설명

줄 코드 설명
22 document.querySelector('#heading') #heading은 id 선택자입니다. CSS 선택자 문법을 그대로 사용합니다
24 document.querySelectorAll('#task-list li') 자손 결합자로 #task-list 안의 모든 li를 선택합니다
28 statusEl.textContent = ... textContent는 HTML을 파싱하지 않고 순수 텍스트로만 삽입하므로 안전합니다
31 firstTask.classList.add('completed') completed 클래스를 추가합니다. CSS에서 정의한 취소선 스타일이 적용됩니다
37 heading.classList.toggle('highlight') highlight 클래스가 없으면 추가하고, 있으면 제거합니다
42 allTasks.forEach(...) NodeList는 forEach를 직접 사용할 수 있습니다

팁: querySelectorAll이 반환하는 NodeList는 배열처럼 forEach를 사용할 수 있습니다. 하지만 map, filter 같은 배열 메서드는 기본적으로 없습니다. 배열로 변환하려면 Array.from(nodeList) 또는 [...nodeList]를 사용하십시오.

베스트 프랙티스: querySelector/querySelectorAll을 사용하면 CSS 선택자를 그대로 쓸 수 있어 직관적입니다. getElementById는 속도가 약간 빠르지만, querySelector('#id')로 대체해도 실무에서 체감 차이는 없습니다.

속성 읽고 쓰기¶

<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>속성 조작 예제</title>
</head>
<body>
  <a id="link" href="https://example.com" target="_blank">예시 링크</a>
  <img id="avatar" src="placeholder.png" alt="아바타">

  <script>
    const link = document.querySelector('#link');
    const img  = document.querySelector('#avatar');

    // getAttribute로 속성 값을 읽습니다
    console.log(link.getAttribute('href'));  // 콘솔 출력: https://example.com

    // setAttribute로 속성 값을 변경합니다
    img.setAttribute('src', 'profile.png');
    img.setAttribute('alt', '사용자 프로필 사진');

    // 자주 쓰는 속성은 직접 프로퍼티로도 접근할 수 있습니다
    console.log(link.href);    // 콘솔 출력: https://example.com/
    console.log(img.alt);      // 콘솔 출력: 사용자 프로필 사진
  </script>
</body>
</html>

줄별 코드 설명

줄 코드 설명
14 link.getAttribute('href') 속성의 원본 문자열 값을 반환합니다
17 img.setAttribute('src', 'profile.png') src 속성을 새 값으로 변경합니다. 이미지가 즉시 교체됩니다
21 link.href DOM 프로퍼티로 직접 접근합니다. getAttribute보다 간결합니다

절 요약¶

  • querySelector/querySelectorAll로 CSS 선택자를 이용해 요소를 선택합니다
  • 텍스트 변경에는 textContent를, 사용자 입력 표시에 innerHTML 사용은 피해야 합니다
  • classList.add/remove/toggle로 클래스를 동적으로 조작하면 CSS와 JavaScript를 깔끔히 분리할 수 있습니다

요소 생성과 삭제¶

도입¶

지금까지는 이미 HTML에 있는 요소를 선택해 변경했습니다. 이제 한 단계 더 나아가, JavaScript만으로 새 요소를 만들어 DOM 트리에 추가하거나 기존 요소를 제거하는 방법을 배웁니다. 이 기능이 있어야 할 일을 입력받아 목록에 추가하거나, 댓글을 동적으로 렌더링하는 웹 앱을 만들 수 있습니다.

핵심 개념 설명¶

createElement와 append¶

document.createElement(tagName)

항목 내용
설명 지정한 태그 이름의 새 요소를 메모리에 생성합니다 (아직 DOM에 추가되지 않은 상태)
매개변수 tagName (string, 필수): 생성할 HTML 태그 이름
반환값 HTMLElement - 새로 생성된 요소
사용 예시 document.createElement('li') → 새 <li> 요소

element.append(...nodes)

항목 내용
설명 요소의 마지막 자식으로 노드나 문자열을 추가합니다
매개변수 nodes (Node 또는 string, 복수 가능): 추가할 노드 또는 텍스트
반환값 undefined
사용 예시 ul.append(li) — ul의 마지막에 li 추가

appendChild vs append: appendChild는 단일 노드만 추가하는 구형 API입니다. append는 여러 노드와 문자열을 한 번에 추가할 수 있는 모던 API입니다. 특별한 이유가 없다면 append를 사용하십시오.

DocumentFragment로 성능 최적화¶

여러 요소를 한꺼번에 추가할 때 반복문에서 매번 DOM에 직접 추가하면, 추가할 때마다 브라우저가 화면을 다시 계산(리플로우)합니다. DocumentFragment(문서 단편)를 사용하면 메모리 안에서 요소들을 조립한 뒤 DOM에 한 번에 추가할 수 있습니다.

코드로 확인하기¶

다음 코드는 배열 데이터를 받아 동적으로 목록 항목을 생성하고 DOM에 추가합니다.

<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>요소 생성과 삭제</title>
  <style>
    #book-list { list-style: none; padding: 0; }
    .book-item {
      display: flex;
      justify-content: space-between;
      align-items: center;
      padding: 8px 12px;
      border: 1px solid #ddd;
      border-radius: 4px;
      margin-bottom: 6px;
    }
    .delete-btn {
      background: #e74c3c;
      color: white;
      border: none;
      padding: 4px 10px;
      border-radius: 4px;
      cursor: pointer;
    }
  </style>
</head>
<body>
  <h2>내 독서 목록</h2>
  <ul id="book-list"></ul>

  <script>
    const books = ['자바스크립트 완벽 가이드', '클린 코드', '리팩터링'];
    const bookList = document.querySelector('#book-list');

    // DocumentFragment를 사용하여 성능을 최적화합니다
    const fragment = document.createDocumentFragment();

    books.forEach((title) => {
      // 새 li 요소를 생성합니다
      const li = document.createElement('li');
      li.classList.add('book-item');

      // 책 제목 span을 생성합니다 (textContent로 안전하게 삽입)
      const titleSpan = document.createElement('span');
      titleSpan.textContent = title;

      // 삭제 버튼을 생성합니다
      const deleteBtn = document.createElement('button');
      deleteBtn.classList.add('delete-btn');
      deleteBtn.textContent = '삭제';

      // 삭제 버튼 클릭 시 해당 li를 제거합니다
      deleteBtn.addEventListener('click', () => {
        li.remove();
      });

      // 자식 요소들을 li에 추가합니다
      li.append(titleSpan, deleteBtn);

      // 아직 DOM에 추가하지 않고 fragment에 쌓습니다
      fragment.append(li);
    });

    // 한 번에 DOM에 추가합니다 (리플로우 1회)
    bookList.append(fragment);

    console.log(`총 ${bookList.children.length}권 렌더링 완료`);
    // 콘솔 출력: 총 3권 렌더링 완료
  </script>

  • 여러 요소를 한꺼번에 추가할 때는 DocumentFragment를 사용해 불필요한 리플로우를 줄입니다

이벤트와 이벤트 흐름¶

도입¶

버튼 클릭, 키보드 입력, 마우스 이동... 사용자가 페이지와 상호작용할 때마다 브라우저는 이벤트(Event)를 발생시킵니다. JavaScript는 이 이벤트를 감지해 원하는 동작을 실행합니다. 이 절에서는 이벤트의 기본 처리 방법과 함께, 많은 개발자가 처음에 놓치는 이벤트 버블링(Bubbling)과 캡처링(Capturing) 개념을 명확히 이해합니다.

핵심 개념 설명¶

addEventListener¶

element.addEventListener(type, listener, options)

항목 내용
설명 요소에 이벤트 리스너를 등록합니다
매개변수 type (string, 필수): 이벤트 유형 ('click', 'input', 'keydown' 등)
listener (Function, 필수): 이벤트 발생 시 호출될 콜백 함수
options (object 또는 boolean, 선택): { capture: false, once: false, passive: false }
반환값 undefined
사용 예시 btn.addEventListener('click', handleClick)

주의: HTML 속성으로 이벤트를 달던 onclick="myFunc()" 방식은 관심사 분리 원칙에 어긋나며 유지보수가 어렵습니다. 항상 addEventListener를 사용하십시오.

이벤트 흐름: 캡처링 → 타깃 → 버블링¶

이벤트가 발생하면 단순히 클릭된 요소에서만 처리되는 것이 아닙니다. DOM 트리를 따라 3단계로 전파됩니다.

단계 방향 설명
1단계: 캡처링(Capturing) document → 타깃 이벤트가 위에서 아래로 내려가며 조상 요소들을 통과합니다
2단계: 타깃(Target) 타깃 요소 실제로 이벤트가 발생한 요소에 도달합니다
3단계: 버블링(Bubbling) 타깃 → document 이벤트가 아래에서 위로 올라가며 조상 요소들로 전파됩니다

비유: 수면에 돌을 던지면 물방울이 깊은 곳까지 내려갔다가(캡처링) 다시 수면 위로 떠오르는(버블링) 과정과 같습니다.

기본적으로 addEventListener는 버블링 단계에서 이벤트를 처리합니다. 세 번째 인수에 true를 주면 캡처링 단계에서 처리합니다.

event.target과 event.currentTarget의 차이¶

속성 의미
event.target 이벤트가 실제로 발생한 요소 (버블링 중에도 변하지 않음)
event.currentTarget 현재 이벤트 핸들러가 등록된 요소 (버블링에 따라 변함)

preventDefault와 stopPropagation¶

event.preventDefault()

항목 내용
설명 이벤트의 기본 동작을 취소합니다 (전파는 계속됨)
사용 예시 링크 클릭 시 페이지 이동 막기, 폼 제출 막기

event.stopPropagation()

항목 내용
설명 이벤트의 전파(버블링/캡처링)를 중단합니다 (기본 동작은 계속됨)
사용 예시 모달 내부 클릭이 배경 클릭으로 인식되지 않게 막기

stopPropagation으로 버블링 막기¶

<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>stopPropagation 예제</title>
  <style>
    #modal-backdrop {
      position: fixed; inset: 0;
      background: rgba(0,0,0,0.5);
      display: flex;
      align-items: center;
      justify-content: center;
    }
    #modal-box {
      background: white;
      padding: 32px;
      border-radius: 8px;
      min-width: 280px;
    }
    .hidden { display: none !important; }
  </style>
</head>
<body>
  <button id="open-btn">모달 열기</button>

  <div id="modal-backdrop" class="hidden">
    <div id="modal-box">
      <h3>안내</h3>
      <p>배경을 클릭하면 모달이 닫힙니다.</p>
      <button id="close-btn">닫기</button>
    </div>
  </div>

  <script>
    const backdrop = document.querySelector('#modal-backdrop');
    const modalBox = document.querySelector('#modal-box');

    // 모달 열기
    document.querySelector('#open-btn').addEventListener('click', () => {
      backdrop.classList.remove('hidden');
    });

    // 배경(backdrop) 클릭 시 모달을 닫습니다
    backdrop.addEventListener('click', () => {
      backdrop.classList.add('hidden');
    });

    // 모달 내부 클릭은 backdrop으로 버블링되지 않도록 막습니다
    modalBox.addEventListener('click', (event) => {
      event.stopPropagation();
    });

    // 닫기 버튼 클릭 시 모달을 닫습니다
    document.querySelector('#close-btn').addEventListener('click', () => {
      backdrop.classList.add('hidden');
    });
  </script>
</body>
</html>

브라우저 동작 결과: - "모달 열기" 버튼 클릭 → 반투명 배경과 함께 모달이 나타납니다 - 모달 내부 클릭 → stopPropagation으로 backdrop에 버블링이 막혀 모달이 닫히지 않습니다 - 모달 외부(배경) 클릭 → backdrop 리스너가 실행되어 모달이 닫힙니다

줄별 코드 설명

줄 코드 설명

46 event.stopPropagation() 모달 박스 내부 클릭이 backdrop으로 버블링되는 것을 막습니다
51 backdrop.classList.add('hidden') hidden 클래스를 추가하면 CSS의 display: none이 적용됩니다

주의: stopPropagation은 꼭 필요한 경우에만 사용하십시오. 무분별하게 사용하면 다른 리스너가 이벤트를 수신하지 못해 예상치 못한 버그가 생깁니다.

절 요약¶

  • addEventListener로 이벤트를 등록하고, 콜백의 event 객체에서 정보를 읽습니다
  • 이벤트는 캡처링(하향) → 타깃 → 버블링(상향) 3단계로 전파됩니다
  • event.target은 실제 이벤트 발생 요소, event.currentTarget은 리스너 등록 요소입니다
  • preventDefault는 기본 동작을, stopPropagation은 전파를 막습니다

이벤트 위임과 동적 UI¶

도입¶

지금까지의 예제들은 미리 만들어진 요소에 리스너를 등록했습니다. 그런데 목록 항목이 동적으로 추가된다면 어떨까요? 새로 생성된 요소에는 이전에 등록한 리스너가 없어서 이벤트가 동작하지 않습니다. 이 문제를 우아하게 해결하는 기법이 이벤트 위임(Event Delegation)입니다.

핵심 개념 설명¶

이벤트 위임(Event Delegation)¶

이벤트 위임은 자식 요소 각각에 리스너를 달지 않고, 공통 부모 요소에 하나의 리스너를 달아 버블링으로 모든 자식의 이벤트를 처리하는 기법입니다.

비유: 각 방마다 경비원을 두는 대신 건물 입구에 한 명을 두어 들어오는 사람을 확인하는 것과 같습니다. 새로운 방이 생겨도 입구 경비원은 그대로 유지됩니다.

이벤트 위임이 필요한 경우: 1. 동적으로 추가되는 요소에 이벤트를 걸어야 할 때 2. 많은 수의 유사한 요소에 같은 이벤트를 걸어야 할 때 (메모리 절약)

event.target과 Element.matches(selector) 조합으로 실제로 클릭된 요소가 원하는 요소인지 확인합니다.

element.matches(selector)

항목 내용
설명 요소가 CSS 선택자와 일치하면 true, 아니면 false를 반환합니다
매개변수 selector (string, 필수): CSS 선택자
반환값 boolean
사용 예시 event.target.matches('.delete-btn')

상태와 UI 동기화¶

동적 UI를 올바르게 만들려면 상태(state)와 UI를 명확히 구분해야 합니다. 상태는 JavaScript 변수에 저장되고, UI는 상태를 보고 그려집니다. 상태가 바뀌면 UI를 다시 그리는 패턴이 유지보수하기 좋습니다.

코드로 확인하기¶

이벤트 위임 기본 패턴¶

<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <title>이벤트 위임 기본</title>
  <style>
    #color-list { list-style: none; padding: 0; display: flex; gap: 8px; flex-wrap: wrap; }
    .color-chip {
      padding: 8px 16px;
      border-radius: 20px;
      cursor: pointer;
      border: 2px solid transparent;
      transition: border-color 0.2s;
    }
    .color-chip.selected { border-color: #2c3e50; }
    #selected-color { margin-top: 12px; font-weight: bold; }
  </style>
</head>
<body>
  <h3>색상 선택</h3>
  <ul id="color-list">
    <li class="color-chip" data-color="빨강" style="background:#e74c3c; color:white;">빨강</li>
    <li class="color-chip" data-color="파랑" style="background:#3498db; color:white;">파랑</li>
    <li class="color-chip" data-color="초록" style="background:#2ecc71; color:white;">초록</li>
    <li class="color-chip" data-color="노랑" style="background:#f1c40f;">노랑</li>
  </ul>
  <p id="selected-color">선택된 색상: 없음</p>

  <script>
    const colorList    = document.querySelector('#color-list');
    const selectedText = document.querySelector('#selected-color');

    // 부모 ul에 리스너를 한 번만 등록합니다 (이벤트 위임)
    colorList.addEventListener('click', (event) => {
      // event.target이 .color-chip 클래스를 가진 요소인지 확인합니다
      if (!event.target.matches('.color-chip')) return;

      // 기존 선택을 해제합니다
      colorList.querySelectorAll('.color-chip').forEach((chip) => {
        chip.classList.remove('selected');
      });

      // 클릭된 요소를 선택 상태로 만듭니다
      event.target.classList.add('selected');

      // data-* 속성에서 값을 읽어 UI를 업데이트합니다
      const color = event.target.dataset.color;
      selectedText.textContent = `선택된 색상: ${color}`;
    });
  </script>
</body>
</html>

브라우저 동작 결과: - 색상 칩 클릭 시 해당 칩에 테두리가 생기고 하단 텍스트가 선택된 색상 이름으로 바뀝니다 - 다른 칩을 클릭하면 이전 선택이 해제되고 새 칩이 선택됩니다

줄별 코드 설명

줄 코드 설명
28 colorList.addEventListener('click', ...) 자식 li 각각이 아닌 부모 ul에 리스너를 등록합니다. 이것이 위임입니다
30 if (!event.target.matches('.color-chip')) return 클릭이 li 안의 다른 요소에서 발생할 수 있으므로, 정확한 대상을 확인합니다
38 event.target.dataset.color HTML의 data-color 속성을 dataset.color로 읽습니다 (data- 접두사 제거, camelCase)

FAQ¶

Q1: querySelector와 getElementById 중 무엇을 써야 하나요?

A1: getElementById는 id만 사용 가능한 반면, querySelector는 CSS 선택자를 모두 지원합니다. 성능 차이는 현대 브라우저에서 거의 없으므로, 일관성을 위해 querySelector('#id-name') 형태를 사용하는 것이 좋습니다. 단, 반복 호출이 매우 많은 극한 성능 상황에서는 getElementById가 약간 빠릅니다.

Q2: innerHTML 대신 textContent만 써야 하나요? innerHTML은 절대 사용하면 안 되나요?

A2: 무조건 금지는 아닙니다. 신뢰할 수 있는 HTML 문자열(서버에서 받은 이미 검증된 HTML, 직접 작성한 리터럴 문자열)이라면 innerHTML을 사용할 수 있습니다. 그러나 사용자 입력값을 그대로 innerHTML에 대입하는 것은 XSS 위험이 있어 절대로 해서는 안 됩니다. 동적 요소 생성은 createElement + textContent 조합이 가장 안전합니다.

Q3: 이벤트 위임을 쓸 때 캡처링 단계의 이벤트도 처리할 수 있나요?

A3: 네. addEventListener의 세 번째 인수에 { capture: true }를 전달하면 캡처링 단계에서 이벤트를 처리합니다. 다만 focus나 blur처럼 버블링되지 않는 이벤트를 위임으로 처리해야 할 때 주로 사용합니다(focusin/focusout은 버블링됩니다). 일반적인 위임에는 기본값(버블링)을 사용하면 충분합니다.

Q4: stopPropagation()과 preventDefault()를 동시에 쓰고 싶을 때는 어떻게 하나요?

A4: 두 메서드를 모두 호출하면 됩니다.

element.addEventListener('click', (event) => {
  event.preventDefault();    // 기본 동작 취소 (예: 링크 이동)
  event.stopPropagation();   // 버블링 중단
});

또는 event.stopImmediatePropagation()을 사용하면 같은 요소의 나머지 리스너들도 실행되지 않습니다.

Q5: NodeList와 Array의 차이는 무엇인가요?

A5: querySelectorAll은 NodeList를 반환합니다. NodeList는 forEach를 지원하지만 map, filter, reduce 같은 배열 메서드는 없습니다. 배열 메서드가 필요하면 Array.from(nodeList) 또는 스프레드 연산자 [...nodeList]로 배열로 변환한 뒤 사용하십시오.
