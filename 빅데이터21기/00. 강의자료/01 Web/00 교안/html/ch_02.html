입문

2장. HTML 기초: 문서 구조와 텍스트¶

학습 목표 - HTML 문서의 기본 골격을 직접 작성할 수 있습니다 - 태그·요소·속성의 개념을 구분하여 설명할 수 있습니다 - 제목, 문단, 목록으로 문서 콘텐츠를 구조화할 수 있습니다 - 주석과 들여쓰기로 가독성 높은 HTML을 작성할 수 있습니다

2.1 HTML 문서의 기본 구조¶

도입¶

모든 건물에는 설계도가 있고, 모든 책에는 목차와 본문이 있습니다. HTML 문서도 마찬가지입니다. 브라우저가 코드를 올바르게 해석하려면 정해진 뼈대 위에 내용을 채워야 합니다. 이 절에서는 그 뼈대가 무엇인지, 각 부분이 어떤 역할을 하는지 배웁니다.

핵심 개념 설명¶

HTML 문서 구조 (HTML Document Structure)¶

HTML 문서 구조(HTML Document Structure)란 DOCTYPE 선언 아래 html 요소가 head(메타 정보)와 body(화면에 보이는 콘텐츠)로 구성되는 HTML 문서의 기본 골격입니다.

책에 비유하면 다음과 같습니다. html은 책 한 권 전체이고, head는 표지와 목차처럼 책의 정보를 담은 앞부분입니다. body는 독자가 실제로 읽는 본문입니다. 독자 눈에 보이는 내용은 모두 body에 들어갑니다.

<!DOCTYPE html> 선언의 의미¶

문서 맨 첫 줄에 오는 <!DOCTYPE html>은 태그가 아닙니다. 브라우저에게 "이 파일은 HTML5 표준 문서입니다"라고 알려 주는 문서 형식 선언(DOCTYPE declaration)입니다.

이 선언을 생략하면 브라우저가 '쿼크 모드(Quirks Mode)'로 전환합니다. 쿼크 모드에서는 오래된 비표준 방식으로 페이지를 렌더링하여 레이아웃이 예상과 다르게 깨질 수 있습니다. 반드시 첫 줄에 작성합니다.

head와 body의 역할 구분¶

영역 역할 예시
head 브라우저와 검색엔진에 전달하는 문서 정보 title, meta, link, script
body 브라우저 화면에 실제로 표시되는 콘텐츠 텍스트, 이미지, 버튼, 목록 등

주의: 화면에 보이게 하고 싶은 내용을 head 안에 넣는 실수가 많습니다. head에 작성한 텍스트는 브라우저 화면에 나타나지 않습니다. 보이는 내용은 반드시 body에 넣습니다.

<meta charset="UTF-8">로 한글 깨짐 방지하기¶

문자 인코딩(charset)은 컴퓨터가 텍스트를 숫자로 변환하는 방식입니다. UTF-8은 한국어를 포함한 세계 모든 문자를 처리하는 국제 표준 인코딩입니다.

이 설정이 없으면 브라우저가 자체적으로 인코딩을 추측하는데, 그 과정에서 한글이 '깨진 문자'로 표시될 수 있습니다. head 안에서 가능한 한 첫 번째 줄에 작성하는 것이 좋습니다.

title 태그와 브라우저 탭¶

title 태그에 작성한 텍스트는 브라우저 탭의 이름과 즐겨찾기 저장 이름, 검색 결과 제목에 표시됩니다. 페이지 내용을 명확히 나타내는 구체적인 이름을 작성합니다.

핵심 개념 코드로 확인하기¶

HTML 문서의 완전한 기본 골격 구조를 직접 확인합니다.

<!DOCTYPE html>
<html lang="ko">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>나의 첫 번째 페이지</title>
  </head>
  <body>
    <h1>안녕하세요!</h1>
    <p>이것은 HTML 문서의 기본 구조입니다.</p>
  </body>
</html>

브라우저에서 이 파일을 열면 다음과 같이 표시됩니다.

[탭 이름: 나의 첫 번째 페이지]

안녕하세요!          ← 큰 제목으로 표시
이것은 HTML 문서의 기본 구조입니다.

줄별 코드 설명

줄 코드 설명
1 <!DOCTYPE html> 브라우저에게 HTML5 표준 문서임을 선언합니다. 반드시 첫 줄에 위치해야 합니다
2 <html lang="ko"> 문서 전체를 감싸는 루트 요소입니다. lang="ko"는 이 문서의 언어가 한국어임을 선언하여 스크린 리더와 검색엔진에 알려 줍니다
3 <head> 화면에 보이지 않는 문서 메타 정보 영역의 시작입니다
4 <meta charset="UTF-8"> 문자 인코딩을 UTF-8로 지정합니다. 한글이 깨지지 않도록 반드시 포함합니다
5 <meta name="viewport" ...> 모바일 브라우저에서 화면 너비에 맞게 표시하도록 설정합니다
6 <title>...</title> 브라우저 탭과 즐겨찾기, 검색 결과에 표시되는 페이지 이름입니다
7 </head> head 영역을 닫습니다
8 <body> 화면에 실제로 보이는 콘텐츠 영역의 시작입니다
9–10 <h1>, <p> 화면에 표시될 제목과 문단 콘텐츠입니다
11 </body> body 영역을 닫습니다
12 </html> 문서 전체를 닫습니다

팁: VS Code에서 빈 .html 파일을 열고 느낌표(!)를 입력한 뒤 Tab 키를 누르면 이 기본 골격이 자동 완성됩니다. Emmet 단축키입니다.

베스트 프랙티스: <html> 태그에 lang 속성을 반드시 지정합니다. 스크린 리더가 적절한 언어로 내용을 읽어 주고, 검색엔진도 페이지 언어를 정확히 파악합니다. 한국어 페이지라면 lang="ko"를 사용합니다.

절 요약¶

  • <!DOCTYPE html>은 브라우저에게 HTML5 표준 문서임을 알리는 선언입니다
  • head는 문서 메타 정보, body는 화면에 보이는 콘텐츠를 담습니다
  • <meta charset="UTF-8">은 한글 깨짐을 방지하기 위해 반드시 포함합니다
  • <html lang="ko">처럼 언어 속성을 지정하면 접근성과 SEO에 유리합니다

2.2 태그, 요소, 속성 이해하기¶

도입¶

HTML을 처음 배울 때 '태그', '요소', '속성'이라는 말이 뒤섞여 혼란스럽습니다. 이 세 용어는 HTML의 핵심 어휘입니다. 마치 택배 상자(요소)에 운송장(속성)을 붙이고 박스의 시작과 끝(여는/닫는 태그)으로 내용물을 감싸는 구조를 이해하면 훨씬 명확해집니다.

핵심 개념 설명¶

태그, 요소, 속성 (Tag, Element, Attribute)¶

HTML을 구성하는 세 가지 기본 단위입니다.

  • 태그(Tag): <와 >로 감싸진 표식입니다. <p>, </p> 같은 꺾쇠 기호 전체를 태그라고 합니다.
  • 요소(Element): 여는 태그부터 닫는 태그까지, 그 사이의 내용을 포함한 전체를 요소라고 합니다.
  • 속성(Attribute): 여는 태그 안에 작성하는 이름="값" 쌍으로, 요소에 추가 정보를 부여합니다.

여는 태그와 닫는 태그의 짝¶

대부분의 HTML 요소는 여는 태그와 닫는 태그가 한 쌍을 이룹니다. 닫는 태그는 태그 이름 앞에 /를 붙입니다.

<p>문단 내용입니다.</p>
  ↑ 여는 태그       ↑ 닫는 태그

태그의 짝이 맞지 않으면 브라우저가 예상치 못한 방식으로 페이지를 표시할 수 있습니다. 항상 여는 태그를 작성했다면 닫는 태그도 함께 작성합니다.

속성(Attribute)과 속성값¶

속성은 여는 태그 안에서 공백으로 구분하여 작성합니다.

<a href="https://example.com" target="_blank">링크 텍스트</a>
      ↑ 속성 이름  ↑ 속성값         ↑ 두 번째 속성

속성값은 반드시 큰따옴표(")로 감쌉니다. 하나의 요소에 여러 속성을 작성할 수 있으며, 순서는 자유입니다.

빈 요소(Void Element)와 중첩 규칙¶

일부 태그는 닫는 태그가 없습니다. 이를 빈 요소(void element)라고 합니다. <br>, <img>, <input>, <hr>, <meta> 등이 이에 해당합니다. 내용(콘텐츠)을 가질 수 없는 요소들입니다.

중첩 규칙: 요소 안에 다른 요소를 포함할 때는 반드시 올바른 순서로 닫아야 합니다.

<!-- 올바른 중첩 -->
<p>이것은 <strong>굵은</strong> 텍스트입니다.</p>

<!-- 잘못된 중첩 (닫는 순서가 엇갈림) -->
<p>이것은 <strong>굵은</p></strong>  <!-- 오류 -->

핵심 개념 코드로 확인하기¶

태그·요소·속성의 구조를 실제 코드로 살펴봅니다.

<!DOCTYPE html>
<html lang="ko">
  <head>
    <meta charset="UTF-8">
    <title>태그와 속성 예시</title>
  </head>
  <body>
    <!-- 기본 요소: 여는 태그 + 콘텐츠 + 닫는 태그 -->
    <p>이것은 문단 요소입니다.</p>

    <!-- 속성을 가진 요소: href가 속성 이름, "https://example.com"이 속성값 -->
    <a href="https://example.com">예시 링크</a>

    <!-- 두 개의 속성을 가진 요소 -->
    <a href="https://example.com" target="_blank">새 탭에서 열기</a>

    <!-- 빈 요소: 닫는 태그 없음 -->
    <img src="photo.jpg" alt="풍경 사진">
    <br>
    <hr>
  </body>
</html>

브라우저에서 열면 다음과 같이 표시됩니다.

이것은 문단 요소입니다.
예시 링크       ← 클릭 가능한 파란색 링크
새 탭에서 열기  ← 클릭하면 새 탭이 열리는 링크
[이미지 또는 대체 텍스트: 풍경 사진]
─────────────────────────────  ← 수평선

줄별 코드 설명

줄 코드 설명
9 <p>이것은 문단 요소입니다.</p> <p>와 </p> 사이의 전체가 하나의 문단 요소입니다
12 <a href="https://example.com"> a 요소에 href 속성을 지정합니다. 속성값은 큰따옴표로 감쌉니다
15 <a href="..." target="_blank"> 하나의 요소에 두 개의 속성을 공백으로 구분하여 나란히 씁니다. target="_blank"는 새 탭으로 열도록 지정합니다
18 <img src="photo.jpg" alt="풍경 사진"> img는 빈 요소이므로 닫는 태그가 없습니다. src로 이미지 경로, alt로 대체 텍스트를 지정합니다
19–20 <br>, <hr> 줄바꿈과 수평선을 나타내는 빈 요소입니다. 닫는 태그를 쓰지 않습니다

<a href="URL" target="_blank" rel="noopener noreferrer">

항목 내용
설명 하이퍼링크를 만드는 앵커(anchor) 요소입니다
주요 속성 href (필수): 이동할 URL
target (선택): _blank이면 새 탭에서 열립니다
rel (선택): target="_blank" 사용 시 보안을 위해 rel="noopener noreferrer" 권장
반환 해당 없음
사용 예시 <a href="https://example.com" target="_blank" rel="noopener noreferrer">링크</a>

주의: target="_blank"를 사용할 때는 반드시 rel="noopener noreferrer"를 함께 작성합니다. 이 속성이 없으면 열린 탭에서 원래 페이지를 조작하는 보안 취약점(탭내빙, tabnabbing)이 발생할 수 있습니다.

베스트 프랙티스: 속성값은 항상 큰따옴표(")로 감쌉니다. 기술적으로는 따옴표 없이 쓰거나 작은따옴표를 사용해도 동작하지만, 팀 일관성과 오류 예방을 위해 큰따옴표를 표준으로 사용합니다.

절 요약¶

  • 태그는 꺾쇠(<>)로 감싸진 표식이고, 요소는 여는 태그·콘텐츠·닫는 태그 전체를 가리킵니다
  • 속성은 여는 태그 안에 이름="값" 형태로 추가 정보를 부여합니다
  • img, br, hr, input 등은 닫는 태그가 없는 빈 요소입니다
  • 요소를 중첩할 때는 안쪽 요소를 먼저 닫아야 합니다

2.3 제목과 문단으로 글 구성하기¶

도입¶

워드프로세서로 문서를 작성할 때 큰 제목, 중간 제목, 소제목, 본문 문단을 구분하듯이 HTML도 제목과 문단을 표현하는 전용 태그가 있습니다. 이 태그들은 단순히 글자 크기를 바꾸는 것이 아니라 문서의 논리적 구조를 표현합니다.

핵심 개념 설명¶

제목 계층 (Heading Hierarchy)¶

HTML은 h1부터 h6까지 여섯 단계의 제목 태그를 제공합니다. 숫자가 작을수록 중요도가 높고 기본 글자 크기도 큽니다.

h1 → 페이지 전체의 대표 제목 (한 페이지에 하나만 권장)
  h2 → 큰 섹션의 제목
    h3 → 소섹션의 제목
      h4 → 세부 항목 제목
        h5 → 더 세부적인 항목
          h6 → 가장 세부적인 항목

보고서에 비유하면 h1은 보고서 표지 제목, h2는 장(章) 제목, h3은 절(節) 제목과 같습니다.

주의: 글자를 크게 보이게 하려고 h1을 여러 번 사용하지 않습니다. 제목 태그는 크기가 아니라 의미와 구조를 표현합니다. 글자 크기는 CSS로 조정합니다. 또한 제목 계층은 건너뛰지 않습니다. h1 다음에 바로 h4를 쓰는 것은 올바르지 않습니다.

문단 (Paragraph)¶

<p> 태그는 하나의 문단을 감쌉니다. 브라우저는 <p> 태그 앞뒤에 자동으로 여백을 추가하여 문단 간 시각적 구분을 만듭니다.

HTML 코드에서 단순히 줄을 바꾸거나 여러 칸 띄워도 브라우저 화면에서는 무시됩니다. 문단을 나누려면 반드시 <p> 태그를 새로 시작해야 합니다.

br과 hr의 올바른 사용¶

  • <br>: 줄바꿈(line break)입니다. 문단은 나누지 않고 그 자리에서 줄만 바꿉니다. 주소, 시(詩), 가사처럼 줄바꿈 자체가 의미를 갖는 곳에 사용합니다. 문단 간격을 만들기 위해 <br>을 여러 번 쓰는 것은 올바른 용법이 아닙니다.
  • <hr>: 수평선(horizontal rule)입니다. 주제가 전환되는 지점에 시각적으로 내용을 구분합니다.

  • <p> 태그로 문단을 나누고, 코드의 빈 줄이나 공백은 화면에 반영되지 않습니다
  • <br>은 줄바꿈, <hr>은 주제 구분을 위한 수평선입니다

2.4 목록과 텍스트 서식¶

도입¶

웹 페이지에서 항목을 나열할 때, 단순히 문단으로 줄줄이 쓰는 것보다 목록으로 표현하면 훨씬 읽기 쉬워집니다. 또한 중요한 단어를 굵게 표시하거나 기울이면 독자의 시선을 자연스럽게 유도할 수 있습니다. 이 절에서는 목록과 텍스트 서식을 표현하는 태그들을 배웁니다.

핵심 개념 설명¶

순서 없는 목록(Unordered List)과 순서 있는 목록(Ordered List)¶

목록은 두 가지 종류가 있습니다.

  • <ul> (Unordered List): 순서 없는 목록입니다. 기본적으로 점(•) 기호가 붙습니다. 항목의 순서가 중요하지 않을 때 사용합니다. 예: 재료 목록, 기능 목록
  • <ol> (Ordered List): 순서 있는 목록입니다. 기본적으로 숫자가 붙습니다. 항목의 순서가 의미를 가질 때 사용합니다. 예: 레시피 순서, 설치 단계

두 경우 모두 각 항목은 <li> (List Item) 태그로 감쌉니다.

목록을 중첩하려면 <li> 안에 새로운 <ul> 또는 <ol>을 작성합니다.

strong과 em으로 의미 강조하기¶

텍스트 강조에는 두 가지 방법이 있습니다.

  • <strong>: 중요도가 높거나 심각한 내용을 표시합니다. 브라우저에서 굵은 글씨로 표시됩니다. 스크린 리더는 강한 강조로 읽습니다.
  • <em> (emphasis): 의미를 강조하거나 특정 단어를 강조합니다. 브라우저에서 기울임꼴로 표시됩니다.

주의: 굵게 보이게 하려고 <strong>을 쓰거나, 기울이려고 <em>을 쓰는 것은 올바른 용법이 아닙니다. 순수하게 시각 효과만 원한다면 CSS를 사용합니다. <strong>과 <em>은 의미를 전달하는 태그입니다.

<span>과 인라인 요소의 활용¶

<span>은 텍스트의 특정 부분을 감쌀 때 사용하는 인라인 요소입니다. <div>처럼 의미 없이 그룹화하는 역할이지만, 줄 안에서 사용합니다. CSS 클래스나 JavaScript 처리를 위한 훅(hook)으로 활용합니다.

핵심 개념 코드로 확인하기¶

순서 없는 목록과 순서 있는 목록, 중첩 목록, 텍스트 강조를 보여 줍니다.

<!DOCTYPE html>
<html lang="ko">
  <head>
    <meta charset="UTF-8">
    <title>목록과 텍스트 서식</title>
  </head>
  <body>
    <h1>나의 취미</h1>

    <!-- 순서 없는 목록 (bullet point) -->
    <h2>좋아하는 취미</h2>
    <ul>
      <li>독서</li>
      <li>요리</li>
      <li>
        운동
        <!-- 중첩 목록: li 안에 ul을 넣습니다 -->
        <ul>
          <li>조깅</li>
          <li>수영</li>
        </ul>
      </li>
    </ul>

    <!-- 순서 있는 목록 (numbered list) -->
    <h2>아침 루틴</h2>
    <ol>
      <li>알람 끄기</li>
      <li>스트레칭 10분</li>
      <li>아침 식사</li>
      <li>출근 준비</li>
    </ol>

    <!-- 텍스트 강조 -->
    <h2>중요한 공지</h2>
    <p>
      이번 행사는 <strong>7월 15일</strong>에 진행됩니다.
      참가 신청은 <em>선착순</em>으로 마감됩니다.
    </p>

    <!-- span으로 일부 텍스트 그룹화 -->
    <p>
      가격은 <span style="color: red;">10,000원</span>입니다.
    </p>
  </body>

  • <span>은 인라인 텍스트를 그룹화하여 CSS 스타일이나 JavaScript 처리에 활용합니다

2.5 주석과 코드 작성 습관¶

도입¶

코드는 컴퓨터만 읽는 것이 아닙니다. 미래의 나 자신, 팀원, 협력자도 읽습니다. 좋은 코드는 누가 읽어도 의도를 빠르게 파악할 수 있도록 정리되어 있습니다. 이 절에서는 HTML 주석과 들여쓰기로 읽기 좋은 코드를 작성하는 방법을 배웁니다.

핵심 개념 설명¶

HTML 주석 (HTML Comment)¶

HTML 주석(comment)은 <!--로 시작해서 -->로 끝납니다. 주석 안의 내용은 브라우저 화면에 표시되지 않습니다.

주석을 활용하면 다음과 같은 이점이 있습니다.

  • 코드 블록의 목적을 설명합니다
  • 임시로 코드를 비활성화할 수 있습니다
  • 섹션 간 구분을 시각적으로 표시합니다

주의: HTML 주석은 브라우저 화면에는 보이지 않지만, 브라우저 개발자 도구나 '페이지 소스 보기'로 누구나 볼 수 있습니다. 비밀번호, API 키, 개인 정보 등 민감한 내용을 주석에 적어두지 않습니다.

들여쓰기로 구조 표현하기¶

HTML 요소는 계층 구조를 가집니다. 들여쓰기는 이 계층을 시각적으로 표현합니다. 들여쓰기 자체는 브라우저 렌더링에 영향을 주지 않지만, 코드 가독성에 큰 영향을 미칩니다.

들여쓰기 규칙 (이 교재의 표준): - 스페이스 2칸을 한 단계로 사용합니다 - 자식 요소는 부모 요소보다 2칸 더 들여씁니다 - 탭 대신 스페이스를 사용합니다 (협업 시 일관성을 위해)

읽기 좋은 코드 작성 습관¶

  1. 섹션 구분: 큰 섹션 사이에 빈 줄을 넣어 시각적으로 구분합니다
  2. 의미 있는 구조: 들여쓰기만으로 구조를 파악할 수 있게 작성합니다
  3. 소문자 태그: HTML 태그는 소문자로 작성합니다 (HTML Living Standard 권장)
  4. 닫는 태그 확인: 여는 태그를 작성한 즉시 닫는 태그를 작성합니다

주석과 들여쓰기가 코드 가독성에 미치는 차이를 비교합니다.

개선 전 (가독성 낮음):

<!DOCTYPE html><html lang="ko"><head><meta charset="UTF-8"><title>페이지</title></head><body><h1>제목</h1><ul><li>항목 1</li><li>항목 2</li></ul></body></html>

좋은 주석 vs 나쁜 주석

구분 예시 이유

절 요약¶

  • HTML 주석은 <!-- 내용 -->으로 작성하며 브라우저 화면에 표시되지 않습니다
  • 주석은 브라우저 소스 보기로 누구나 볼 수 있으므로 민감한 정보를 담지 않습니다
  • 들여쓰기는 2칸 스페이스를 기준으로 계층 구조를 시각적으로 표현합니다
  • 소문자 태그, 큰따옴표 속성값, 닫는 태그 확인이 일관된 코드 습관의 핵심입니다

FAQ¶

Q1. <!DOCTYPE html>은 왜 매번 작성해야 하나요?

A1. <!DOCTYPE html>은 브라우저에게 이 파일이 최신 HTML5 표준을 따른다고 알리는 선언입니다. 이 선언이 없으면 브라우저는 '쿼크 모드(Quirks Mode)'로 동작하여 구형 브라우저 호환성을 위해 일부 CSS 및 레이아웃 계산을 다르게 처리합니다. 모든 최신 브라우저에서 예측 가능하게 작동하려면 반드시 첫 줄에 포함해야 합니다.

Q2. <b>와 <strong>, <i>와 <em>은 어떻게 다른가요?

A2. 시각적 결과는 같지만 의미가 다릅니다. <b>(bold)는 단순히 굵게 표시하는 표현 목적의 태그이고, <strong>은 내용이 중요하거나 긴박하다는 의미를 전달합니다. 마찬가지로 <i>(italic)는 기울임꼴 표시 목적이고, <em>은 특정 단어를 강조한다는 의미를 가집니다. 스크린 리더와 검색엔진은 <strong>과 <em>을 중요한 내용으로 처리합니다. HTML Living Standard에서는 의미 있는 <strong>과 <em> 사용을 권장합니다.

Q3. <div>와 <span>은 언제 사용하나요?

A3. <div>는 블록 수준(block-level) 요소로, 여러 요소를 한 덩어리로 묶을 때 사용합니다. <span>은 인라인(inline) 요소로, 텍스트의 일부분에만 스타일을 적용하거나 JavaScript 처리를 위해 그룹화할 때 사용합니다. 두 태그 모두 의미를 가지지 않는 '컨테이너'입니다. 의미를 전달해야 하는 구역에는 <header>, <main>, <section>, <article> 등 시맨틱 태그를 사용하고, 단순히 스타일 적용을 위한 묶음이 필요할 때 <div>와 <span>을 사용합니다.

Q4. HTML 태그 이름은 대문자로 써도 되나요?

A4. 브라우저는 <P>, <DIV> 같은 대문자 태그도 인식하고 처리합니다. 그러나 HTML Living Standard 및 MDN 권장 사례는 소문자 작성입니다. 대소문자가 섞이면 코드의 일관성이 떨어지고 가독성이 낮아집니다. 이 교재 전체에서 소문자 태그를 표준으로 사용합니다.

Q5. <br> 태그를 여러 개 연속으로 써서 여백을 만들어도 되나요?

A5. 기술적으로는 동작하지만 좋은 방법이 아닙니다. <br>은 줄바꿈 자체가 의미를 갖는 곳(주소, 시, 가사)에 사용합니다. 문단 간 여백이나 요소 사이 간격은 CSS의 margin과 padding으로 처리합니다. <br>을 반복해서 여백을 만드는 것은 콘텐츠와 표현을 혼용하는 안티패턴입니다.
